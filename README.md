# Пошук відділення Нової пошти

Мінімальний внутрішній веб-інструмент для швидкого пошуку відділень/поштоматів і копіювання адреси.

## Запуск

1. Розпакуйте архів.
2. Відкрийте папку через локальний веб-сервер.
   - VS Code: розширення Live Server → Open with Live Server.
   - або: `python -m http.server 8080`
3. Відкрийте `http://localhost:8080`.
4. Натисніть ⚙ та вставте API Key Нової пошти.

## API Key

Ключ зберігається в `localStorage` поточного браузера.

> Для публічного сайту не варто зберігати приватний API Key у frontend-коді.
> У такому випадку винесіть запити до Нової пошти на власний backend/serverless function.

## Що вміє

- пошук населеного пункту;
- завантаження актуальних точок Нової пошти через API;
- пошук за номером або частиною адреси;
- фільтр "усі / відділення / вантажні відділення / поштомати";
- копіювання готового рядка;
- локальний пошук поштових індексів Укрпошти за офіційними відкритими даними;
- адаптивний мобільний дизайн.

## База поштових індексів Укрпошти

Джерело даних: відкриті дані АТ «Укрпошта» — набір [«Перелік поштових індексів та відділень поштового зв’язку України»](https://data.gov.ua/dataset/post-index-and-braches) на державному порталі відкритих даних.

Поточна локальна база: `data/ukrposhta-indexes.json`. База оновлена: **08.08.2025**.

JSON використовує компактний словниковий формат. Масив `schema` описує позиції у кожному елементі `records`; текстові значення беруться з масивів `cities`, `regions`, `districts`, `streets` та `offices`. Це зменшує розмір frontend-файлу без зміни вихідних значень.

### Як оновити базу

1. Відкрийте офіційну [сторінку набору](https://data.gov.ua/dataset/post-index-and-braches) і завантажте найновіший ресурс.
2. Розпакуйте `.7z` та знайдіть CSV. Актуальний файл має роздільник `;` і кодування Windows-1251.
3. Запустіть конвертер, передавши шлях до CSV і дату даних:

   ```text
   node tools/update-ukrposhta-data.js "C:\path\source.csv" "data\ukrposhta-indexes.json" "DD.MM.YYYY"
   ```

4. Перевірте поле `updated` та кількість `recordCount` у згенерованому JSON, після чого опублікуйте оновлений файл разом із сайтом.

Конвертер читає фактичні українські колонки офіційного CSV, видаляє точні дублікати та формує статичний JSON. API Key і серверна частина не потрібні.
